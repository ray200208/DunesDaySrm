Theme:
Smart Public Transport Operations

Challenge:
Predict the transit problem

Problem Statement:
Predict overcrowding, demand supply imbalance, abnormal ridership, delays or other transit operational problems and recommend an operational response. 

Reference the sample data located in the /data/ directory when building features or database schemas.

The raw dataset consists of CSVs, Shapefiles, and transit data located in the /Data/, /Public Transport/, and /Road Network Old CMA/ directories. DO NOT attempt to read these directories directly. The schema for these files is defined in data-schema.md
